# Glyph OCR 설계

## 목표

개인용 Electron/Ollama 앱을 범용 Windows 문서 OCR 앱으로 교체한다. Rust가 파일 처리, 작업 저장, 모델 다운로드, 추론 수명, 큐, 내보내기를 담당하고 Tauri 2 + React가 문서 목록·원본·인식 결과 UI를 제공한다.

## 처리 경로

```text
파일 / 드롭 / 클립보드 → Rust 가져오기 → 작업 폴더에 원본과 페이지 이미지 저장
                                    ↓
                        필요한 모델 확인 / 이어받기 / 해시 검증
                                    ↓
영역 탐지 해제: 페이지 전체 → llama.cpp / PaddleOCR-VL 1.6 → 결과
영역 탐지 선택: PP-DocLayoutV3 → 위치·읽기 순서 → 영역별 PaddleOCR-VL → 결과
                                    ↓
                    자동 저장 / 편집 / TXT·MD·HTML·JSON 내보내기
```

기본값은 전체 페이지 단일 인식이다. 영역 탐지는 사용자가 선택하는 명시적 기능이다. 별도의 이미지 타일링, 중복 인식 병합, 자모 치환 및 코드 복원 로직을 사용하지 않는다.

## 영역 탐지 실행

빌드 시 공식 Transformers 구현을 고정 입력 1×3×800×800의 ONNX 그래프로 내보낸다. 그래프의 853개 초기화 텐서는 공식 Safetensors 파일의 바이트 오프셋을 참조한다. 그래프에는 학습된 가중치를 포함하지 않는다. 변환 시 PyTorch와 ONNX Runtime의 출력을 수치 비교한다.

설치된 앱은 Rust `ort`와 동봉한 ONNX Runtime CPU 라이브러리로 탐지한다. Python이나 PyTorch는 설치하지 않는다. 공식 전처리(800×800 RGB, 1/255)와 클래스 점수·쌍별 순서 투표를 적용한다. 축에 평행한 사각형 좌표를 페이지 픽셀로 변환한다. 곡면 다각형 마스크는 현재 출력하지 않는다.

영역별 OCR 응답을 원문으로 보존하고 표의 OTSL을 병합 셀을 포함한 HTML로 변환한다. 각 영역과 최종 문서의 텍스트를 구분해 보존한다. 탐지된 상위 이미지에 텍스트 영역이 포함되면 상위 이미지는 중복 OCR하지 않는다. 탐지 결과가 없으면 안내와 함께 전체 페이지를 인식한다.

## 모델과 배포

- 모델 저장소의 리비전·파일 크기·SHA-256은 `src-tauri/models.json`에 고정한다.
- GGUF 두 파일은 첫 스캔, DocLayoutV3는 영역 탐지를 선택한 스캔에 준비한다.
- 부분 파일은 `.part`로 저장한다. HTTP Range와 Content-Range를 확인하며 서버가 Range를 무시하면 덮어쓴다. 크기·SHA-256을 확인한 뒤 정식 파일명으로 바꾼다.
- 일시정지·중단·앱 재실행 후에도 받은 부분을 유지한다.
- 설치기는 Inno Setup의 단일 x64 EXE다. llama.cpp CPU/Vulkan, PDFium, ONNX Runtime, MSVC CRT, WebView2 오프라인 설치 파일과 고지문을 포함한다.
- 설치된 모델은 사용자 로컬 데이터 폴더에 저장하며 LM Studio 경로에 의존하지 않는다.
- Git에는 소스·고정 버전 정의·빌드 스크립트만 넣는다.
- vMAJOR.MINOR.PATCH 태그는 GitHub Actions에서 해당 커밋을 빌드하여 Release에 첨부한다.

## 저장과 실행 안정성

원본 사본과 페이지 이미지는 UUID 파일명을 사용하고 프로젝트 내 상대 경로를 검증한다. 저장은 임시 파일과 원자 교체 및 백업을 사용한다. 중단된 스캔 상태는 다음 작업 열기에서 대기로 복구한다. 재인식은 완료 페이지도 허용하며 성공한 새 결과로 갱신한다.

llama-server는 루프백 임시 포트·세션별 API 키·숨겨진 프로세스로 실행한다. Rust가 프로세스를 소유하고 취소·종료·시작 실패 시 정리한다. Windows Job Object로 부모 강제 종료 시에도 서버를 종료한다. GPU 자동 모드는 Vulkan 초기화 실패 시 CPU로 전환한다.

React 결과 렌더링과 HTML 내보내기에서 모델이 반환한 HTML을 정제하고 외부 이미지·스크립트를 실행하지 않는다. OCR 요청은 로컬 서버에만 보내며 모델 다운로드 요청에 사용자 문서를 포함하지 않는다.

## UI

- 목록: 단일 선택, Ctrl 개별 선택, Shift 범위, Ctrl+Shift 범위 추가, Ctrl+A 현재 필터 전체, Esc 선택 해제.
- 선택 스캔과 전체 스캔은 상태에 관계없이 반복 실행 가능.
- 문서 목록 주변 Ctrl+V, 입력 칸에서 이미지 붙여넣기, 창 드래그 앤 드롭.
- 문서 / 편집 / 구조 / 원문 탭, 원본 영역 오버레이, 사용자 지침, 만화 모드.
- 우측 하단 다운로드 팝업: 진행률·속도·일시정지·계속·중단·재실행 이어받기.
