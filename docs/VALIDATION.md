# 검증 기록

검증일: 2026-09-03. Windows x64 개발 PC에서 수행했다. 이 문서는 실제 확인한 동작과 아직 검증하지 않은 환경을 구분한다.

## 자동 검증

- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- Rust 검사·포맷 검사와 단위 테스트 14개 통과.
- npm 보안 감사: 알려진 취약점 0개.
- 네이티브 리소스 132개에 대한 번들 매니페스트 검증 통과.
- 레이아웃 그래프 변환 시 동일 입력에 대한 PyTorch / ONNX Runtime 출력 수치 비교 통과.
- 태그 버전 적용 스크립트를 별도 복사본에서 v1.0.0으로 실행하여 package.json, package-lock.json, Cargo.toml, Cargo.lock, Tauri 설정 일치 확인.
- GitHub Actions YAML 구문, 태그 트리거와 Release 쓰기 권한 확인.

단위 테스트는 작업 저장·복구·경로 검증, 다운로드 Range 응답과 부분 파일 재시작, 레이아웃 좌표·읽기 순서, 한국어 원문 보존, HTML 정제, 표 병합 셀·불완전한 OTSL 응답, 구조화 내보내기를 다룬다.

## 앱 동작

- CPU 전체 페이지 OCR: 한국어 캡처에서 제목·이름·금액·이메일 인식 확인.
- Vulkan 전체 페이지 OCR: 2페이지 PDF 인식 확인.
- 실제 클립보드 이미지의 Ctrl+V 추가 확인. 목록 주변 및 검색 입력에 포커스가 있을 때도 이미지 가져오기 확인.
- Tauri의 파일 드롭 이벤트 경로로 파일 가져오기 확인. 물리적인 OS 드래그 제스처의 자동화 검증은 수행하지 않았다.
- 클릭, Ctrl+클릭, Shift+클릭, Ctrl+Shift+클릭, Ctrl+A에 따른 선택 수 검증.
- 완료한 페이지 중 두 페이지만 선택하고 모드·지침을 변경하여 재인식 완료. 선택하지 않은 페이지의 결과 유지 확인.
- 영역 탐지 사용 시 실제 PP-DocLayoutV3가 송장 페이지에서 제목·본문·표·합계 5개 영역을 탐지하고, 영역별 OCR 완료.
- 탐지 좌표가 페이지 안에 있고 원본 오버레이에 대응하는지 확인. 표 셀 결과와 JSON의 bbox·읽기 순서·영역 텍스트 확인.
- 원본/결과 화면, 표 결과, 영역 오버레이, 다운로드 일시정지 팝업을 스크린샷으로 확인.
- 불완전한 표 토큰 응답을 유효한 표로 오인하지 않고 원문과 경고로 보존하는 회귀 테스트 통과.

## 모델 다운로드

실제 공식 Hugging Face 다운로드에서 다음 순서를 확인했다.

1. 75,497,472바이트에서 일시정지 후 수신량이 유지됨.
2. 중단 후 스캔이 종료되고 부분 파일이 유지됨.
3. 앱 재시작 후 같은 수신량의 중단 상태가 복구됨.
4. 이어받기 후 총 1,950,810,084바이트의 세 모델 파일 다운로드 완료.
5. 고정 SHA-256 검증 통과 후 실제 OCR과 영역 탐지 실행.

최종 빌드에서는 요청당 Range 크기를 4MiB에서 32MiB로 조정했다. 동일한 Range 검증 코드의 단위 테스트는 통과했으며, 크기 변경 후 전체 네트워크 다운로드를 반복하지는 않았다. 네트워크 응답이 지연되면 일시정지·중단 반영까지 현재 요청의 제한 시간 이내로 지연될 수 있다.
