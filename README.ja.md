<h1 align="center">FastFileOCR</h1>
<p align="center"><strong>Simple / Fast / Accurate</strong></p>

**FastFileOCR** は、スキャンした書類、写真、PCのスクリーンショットを編集可能なテキストに変換するWindowsアプリです。OCR処理はお使いのPC上で実行されます。

|                    | 対応内容                                                                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| OCRモデル          | **[PaddleOCR-VL 1.6](https://huggingface.co/PaddlePaddle/PaddleOCR-VL-1.6-GGUF)**、領域検出には **PP-DocLayoutV3** を使用                            |
| コアの開発言語     | **Rust**                                                                                                                                             |
| 文字認識の対応言語 | 日本語、英語、韓国語、中国語など — **[モデルは109言語に対応](https://www.paddleocr.ai/main/en/version3.x/algorithm/PaddleOCR-VL/PaddleOCR-VL.html)** |
| アプリの表示言語   | **English、한국어、日本語**                                                                                                                          |
| 入力ファイル       | **PDF、PNG、JPG/JPEG、WEBP、BMP**、クリップボードの画像                                                                                              |
| 出力形式           | **TXT、Markdown、HTML、JSON**                                                                                                                        |
| 対応環境           | **Windows 10/11 x64**                                                                                                                                |
| 実行デバイス       | **自動、CPU、Vulkan、NVIDIA CUDA**                                                                                                                   |

WordやPowerPointのファイルはPDFに書き出してから追加してください。暗号化されたPDFは、先にロックを解除する必要があります。

## 主な機能

- ファイル選択、ドラッグ＆ドロップ、**Ctrl+V**でPDFや画像を追加できます。
- OCRの前に領域を検出し、位置と読み順を保持します。**初期設定では有効**です。チェックを外すとページ全体のOCRに切り替わります。
- 文書、通常のテキスト、表、数式、漫画の認識モードを選べます。
- 指示を自由に入力し、同じページを何度でも再スキャンできます。
- Ctrl、Shift、Ctrl+Aで複数のページを選択できます。選択済みのページをもう一度クリックすると選択が解除されます。
- 結果を確認・編集し、テキストや構造化データとして保存できます。

## 使い始める

1. [リリース](../../releases/latest)からWindows x64用インストーラーをダウンロードします。
2. 言語と、設定・モデル・ワークスペースを保存するフォルダーを選びます。
3. アプリを開き、ファイルを追加して認識モードを選び、スキャンします。

付属の[サンプル文書](docs/assets/sample-invoice.pdf)で試すこともできます。

初回のスキャン時に、Hugging Faceから約 **1.82 GB** のOCRモデルと約 **133 MB** の領域検出モデルをダウンロードします。領域検出を無効にした場合はOCRモデルのみ必要です。ダウンロードは一時停止・中断でき、アプリの再起動後も続きから再開できます。モデルの準備が完了すると、オフラインでOCRを実行できます。文書や認識結果はアップロードされません。

## 領域と文書構造

領域検出は初期設定で有効です。元のページ上でテキスト領域、表、見出しの位置を確認できます。JSON出力には領域の座標、読み順、領域ごとの認識結果が含まれます。

<img src="docs/assets/regions.png" alt="領域検出と構造化されたOCR結果">

装飾的な見出しや特殊なレイアウトは、領域検出で見落とす場合があります。文字が欠けている場合は領域検出を無効にし、ページ全体を再スキャンしてください。テキストとHTMLは読み順に沿って出力され、元のページの配置を完全に再現するものではありません。漫画モードは認識指示と汎用の文書検出モデルを使用するため、複雑な吹き出しや読み方向は再認識が必要な場合があります。

## 自分に合わせて設定する

設定で **English、한국어、日本語** を選択できます。既定は英語で、初回起動時はインストール中に選択した言語が使われます。アプリの表示言語と、文書の認識言語は別のものです。

OCRモデルと実行デバイスを選び、モデルごとのオプションや指示を調整できます。専用のグラフィックカードがなくてもCPUで実行できます。CUDAには対応するNVIDIA GPUとドライバーが必要です。

<img src="docs/assets/settings.png" alt="モデルと実行デバイスを選択する認識設定">

設定から更新を確認でき、起動時の通知も有効にできます。更新のインストール時には、既存の設定を引き継ぐか、設定をバックアップして初期設定から始めるかを選べます。ダウンロード済みのモデルと文書は保持されます。アンインストール時は、設定・モデルの削除と、アプリのデータフォルダー内にあるワークスペースの削除を個別に選択できます。

CPUエンジンと文書処理ライブラリは同梱されています。CUDA・Vulkanエンジンは初回使用時に自動ダウンロードします。**CUDAは約537 MB、Vulkanは約34 MB**で、一時停止・再開とアプリ更新後の再利用に対応しています。自動モードは対応するGPUエンジンを1つ選択し、必要に応じてCPUに切り替えます。

Rust、Python、Node.js、LM Studio、CUDA Toolkitを別途インストールする必要はありません。GPU処理には対応するグラフィックドライバーが必要です。
